# Data layout and external Hamiltonians

This repository includes the compact source tables and derived diagnostics
needed to render the article figures.  It deliberately does **not** redistribute
third-party molecular FCIDUMPs, trained checkpoints, sampler states, or frozen
production supports.

## Hamiltonian manifest

`hamiltonian_manifest.csv` is the machine-readable provenance ledger.  It
distinguishes four byte-level quantities that should not be conflated:

- the pinned upstream URL and commit;
- the SHA-256 and byte count of the upstream bytes;
- any deterministic local materialization (including newline normalization or
  frozen-core reduction); and
- the SHA-256 and byte count of the exact copy used in the analysis.

Every third-party row is marked `not_redistributed`.  A repository license is
recorded as provenance, not as an assertion that every data file is covered by
that license.  The public repository therefore directs each user to the
original host and verifies the result locally.

List the records with:

```bash
python scripts/hamiltonian_artifacts.py list
```

Download the inputs whose original locations have been verified:

```bash
python scripts/hamiltonian_artifacts.py \
  --destination data/hamiltonians \
  fetch cdfci_n2_ccpvdz cdfci_h2o_ccpvdz
```

The command checks the downloaded upstream hash before applying the recorded
newline conversion and then checks the exact analysis-copy hash. Local files under `data/hamiltonians/` are
ignored by Git so that a later `git add -A` cannot accidentally republish them.

## Locally generated and derived Hamiltonians

NH3 and HCN were generated by the authors from the public G2 geometries, not
copied as FCIDUMPs.  Rebuild them with the optional PySCF dependency:

```bash
python -m pip install -e ".[hamiltonians]"
python scripts/generate_g2_hamiltonians.py
```

The Cr2 CAS(24e,30o) Hamiltonian is derived from the pinned CDFCI 48e/42o
input.  First retrieve the source, then freeze the listed Mg-core orbitals:

```bash
python scripts/hamiltonian_artifacts.py \
  --destination data/hamiltonians fetch cdfci_cr2_48e42o
python scripts/freeze_fcidump_core.py \
  --input data/hamiltonians/Cr2-Ahlrichs-VDZ-CDFCI/FCIDUMP \
  --output data/hamiltonians/Cr2-Ahlrichs-SV-CAS24e30o/FCIDUMP \
  --core-orbitals 1,2,3,4,14,18,24,25,26,27,35,39 \
  --reference-energy -2086.420934 \
  --reference-algorithm "SHCI weighted-quadratic extrapolation, HF core"
python scripts/hamiltonian_artifacts.py \
  --destination data/hamiltonians verify cr2_cas24e30o
```

## Fe2S2

The original Fe2S2 CAS(30e,20o) Hamiltonian is the Li--Chan active-space model
from their DMRG work.  Its exact file is publicly retrievable from the authors'
repository at the pinned revision in the manifest.  That repository has no
license file, so this release links to and verifies the original rather than
redistributing it.  Our paper uses our own unitary canonical-RHF rotation of
that Hamiltonian; the transformation recipe and output checksum are retained.

```bash
python scripts/hamiltonian_artifacts.py \
  --destination data/hamiltonians fetch li_chan_fe2s2_source
python scripts/prepare_fe2s2_rhf.py \
  --input data/hamiltonians/Fe2S2-CAS30e20o/FCIDUMP \
  --output-dir data/hamiltonians/Fe2S2-CAS30e20o-RHF
python scripts/hamiltonian_artifacts.py \
  --destination data/hamiltonians verify li_chan_fe2s2_rhf
```

These commands download from the source authors and create the RHF derivative
locally; neither file is added to this repository.

The generated Hubbard FCIDUMPs in `benchmark_cases/fcidump/` are the only
Hamiltonian files committed here, and their generator is included.

See `docs/hamiltonian_provenance.md` for the system-by-system account.
