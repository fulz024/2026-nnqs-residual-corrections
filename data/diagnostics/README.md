# Derived diagnostic data

`large_system_failure_diagnosis/` contains the compact numerical inputs for
the root-locality figure. For each system, one file stores the first eight
Ritz roots of the retained support together with their NNQS overlaps; the
second stores the first eight roots after augmentation by the deterministic
screened residual shell. Energies are reported as errors in millihartree
relative to the reference value used in the article.

Each file contains only the quantities needed to reproduce the panel.
